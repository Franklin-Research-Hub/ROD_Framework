# Contributing

This repository is a governed, proprietary framework archive and is not an open public contribution platform.

## Scope

Contributions are limited to framework documentation, governance records, and internal structural updates as approved by the root creator.

## Rules

1. Preserve the repository structure.
2. Keep the framework metadata model intact.
3. Keep creator records in `Creator/` (Layer 2), following the rules in `Foundation/` (Layer 1).
4. Root files and supporting layer documents are not creator records. Retained `docs/` and `framework/` material is legacy documentation, not the primary active structure.
5. Do not alter the root authority or ownership claims without review.

## Workflow

- update supporting documentation in the repo as needed
- maintain metadata consistency in framework nodes
- keep the root node authoritative and unchanged unless formally revised

## Contact

Contact the framework owner for access, approval, and contribution permissions.
