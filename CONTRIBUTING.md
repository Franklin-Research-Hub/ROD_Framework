# Contributing

This repository is a governed, proprietary framework archive and is not an open public contribution platform.

## Scope

Contributions are limited to framework documentation, governance records, and internal structural updates as approved by the root creator.

## Rules

1. Preserve the repository structure and layer boundaries.
2. Keep the framework metadata model intact as defined in `Foundation/metadata-model.md`.
3. `Foundation/` (Layer 1) defines architectural rules, governance, metadata, and validation criteria.
4. `Creator/` (Layer 2) contains creator records and creator-layer applications; higher layers depend on lower layers, never the reverse.
5. Do not alter the root creator authority or ownership claims without review.

## Workflow

- update supporting documentation and layer records as needed
- maintain metadata consistency across layers
- keep the root creator record authoritative and unchanged unless formally revised

## Contact

Contact the framework owner for access, approval, and contribution permissions.
