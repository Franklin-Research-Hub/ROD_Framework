# Creator (Layer 2)

## 1. Purpose
Creator is the Layer 2 branch for creator identity, attribution, indexed records, and website application in `ROD_Framework`. Its current record anchor is `0.00`.

## 2. Document Set
| Document | Responsibility |
|---|---|
| [README.md](README.md) | Branch entry and document register |
| [INDEX.md](INDEX.md) | Authoritative register of Creator records |
| [0.00-creator.md](0.00-creator.md) | Canonical creator record |
| [website-application.md](website-application.md) | Application of approved record content |
| [tree-branch.md](tree-branch.md) | Local tree, including branch-owned records |

## 3. Canonical Reference Chain
`Creator/` → `Creator/README.md` → `Creator/INDEX.md` → `Creator/0.00-creator.md`

The index registers the record; the record owns creator content. This entry describes the branch, the local tree describes placement, and the application document describes use without becoming a competing canonical record.

## 4. Metadata Inclusion
Records may include identity, role, authority, attribution, and approved biography, portfolio references, or extended profile material. Follow the [Foundation metadata model](../Foundation/metadata-model.md). `0.00` is an identifier, not a version; section numbers are local document order.

## 5. Relationship to Foundation
Creator depends on [Foundation](../Foundation/README.md) and follows the [master structure](../MASTER-TREE-BRANCH.md). The master tree and repo-wide TOC expose the branch index, not its record file. Local registration and enumeration of the record are intentional.

## 6. Status
Active-working Creator baseline. Record and structural changes require controlled approval; application guidance does not grant publication or licensing permission.
