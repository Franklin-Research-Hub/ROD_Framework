## 4. Metadata Reference
Creator records follow the metadata model defined in [Foundation/metadata-model.md](../Foundation/metadata-model.md) and the inclusion rules codified in [0.00-creator.md](0.00-creator.md). ## 5. Adding New Records

2. Add the record entry to Section 2 of this index.
3. Update [tree-branch.md](tree-branch.md) and [MASTER-TREE-BRANCH.md](../MASTER-TREE-BRANCH.md).
