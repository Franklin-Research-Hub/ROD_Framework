# Approval Form Template

**Document Role: General Structural Template**

This document provides a generalized structural schema and template guide for framework proposal approval forms across all approval tiers. It serves as an architectural template, distinct from specific applied form implementations (such as Form B: [0.V.9.00 Low-Risk Creator Approval Form](../validation/0.V.9.00-low-risk-creator-approval-form.md) or [0.V.10.00 Full-Chain Approval Form](../validation/0.V.10.00-full-chain-approval-form.md)).

Use this Markdown template to design new approval forms, or use the [form text sources](../forms/README.md) for existing form implementations. No editable PDF is included in this repository.

## Approval Form Structure

### Header Section
- Proposal Title
- Submission Date
- Proposer Name/Role
- Framework Node/Layer
- Approval Path Selection (radio buttons)

### Approval Path Options
- [ ] Full Chain Approval (Jack → Karen → Terrell)
- [ ] Creator-Only / Terrell-Only Approval
- [ ] Low-Threat Fast-Track (Terrell-Only)

### Proposal Description Section
- Brief Description (1-2 paragraphs)
- Framework Impact
- Implementation Timeline
- Dependencies

### Threat Assessment Section (Full Chain Only)
- Operational Risk Assessment
- Compliance & Governance Risk Assessment
- IT Security & Records Management Risk Assessment

### Creator-Only Assessment Section
- Threat Identification (Yes/No)
- Brief Justification for No Threats
- Terrell-Only Review Statement

### Approval Sign-Off Section

**For Full Chain:**
1. Jack Brown (Chief Deputy Register) - Signature / Date
2. Karen Johnson (Register of Deeds) - Signature / Date
3. Terrell Wilson (Deputy Register IT) - Signature / Date

**For Creator-Only:**
1. Terrell Wilson (Deputy Register IT) - Signature / Date

### Final Decision Section
- [ ] APPROVED
- [ ] APPROVED WITH CONDITIONS
- [ ] REJECTED
- [ ] ESCALATED

Conditions/Notes: _______________________________________________

### Archive Information
- Approval Completed Date
- Archive Location
- Next Layer Implementation Date (if approved)
