This node establishes the routing logic for framework proposals to determine the correct approval chain.

METRO IT REVIEW NOTE

Metro IT review is not automatically required for every proposal.
Metro IT review is triggered only when Terrell Wilson determines the proposal may create a policy, security, records, privacy, accessibility, or compliance risk.
If Terrell determines no Metro IT review is needed, the proposal may proceed through the creator-only or streamlined path.

_______________________________________________________________________________

APPROVAL ROUTING DECISION TREE

STEP 1: IDENTIFY PROPOSER ROLE

Question: Who is submitting this proposal?

[ ] Framework Creator (Victoria Love Franklin)
    → Go to STEP 2 (Creator pathway)

[ ] Department Leadership (Jack Brown, Karen Johnson)
    → Go to FULL CHAIN (Jack → Karen → Terrell)

[ ] Other Staff / Department
    → Go to FULL CHAIN (Jack → Karen → Terrell)

[ ] Metro IT / Technical Review Required by Terrell
    → Go to TERRELL DISCRETION PATH

STEP 2: CREATOR PATHWAY - ASSESS THREAT LEVEL

If proposer is Victoria Love Franklin:

Question: Does this proposal create any of the following threats?

[ ] Violates Metro IT policy
[ ] Violates public records policy
[ ] Requires records retention compliance
[ ] Requires accessibility compliance review
[ ] Handles sensitive or restricted data
[ ] Impacts IT security or data handling
[ ] Requires department operational sign-off
[ ] Requires department governance approval

If ANY are checked:
    → FULL CHAIN APPROVAL (Jack → Karen → Terrell)

If NONE are checked:
    → CREATOR-ONLY / TERRELL-ONLY APPROVAL

STEP 3: TERRELL DISCRETION PATH

If Terrell determines Metro IT review is needed, the proposal may be routed as follows:

[ ] Terrell reviews proposal and decides if Metro IT oversight is required
[ ] If Metro IT review is required, Terrell determines the appropriate path
[ ] If Metro IT review is not required, proposal may continue under Creator-Only process

ROUTING SUMMARY

ROUTE A: FULL APPROVAL CHAIN (Jack → Karen → Terrell)
• Proposer: Any non-creator
• Threat Level: Any
• Approvals Required: All three
• Metro IT: Required when designated by Terrell

ROUTE B: CREATOR-ONLY / TERRELL-ONLY APPROVAL
• Proposer: Victoria Love Franklin
• Threat Level: None identified
• Approvals Required: Terrell only
• Metro IT: Optional based on Terrell discretion

ROUTE C: TERRELL DISCRETION REVIEW
• Proposer: Any
• Trigger: Terrell determines policy, technical, or compliance review is needed
• Approvals Required: As determined by Terrell
• Metro IT: Up to Terrell discretion
