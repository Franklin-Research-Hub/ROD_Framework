# ROD Framework

The `ROD_Framework` repository defines the ROD Framework as a proprietary layered documentation architecture rooted in creator authority and structured for governance, traceability, and implementation.

## Purpose
This repository exists to:
- document the framework architecture
- preserve its governance structure
- define its layered documentation model
- maintain creator-linked source authority

## Layers
- `Foundation/` (Layer 1) — Structural rules, system architecture, governance, metadata model, and validation references.
- `Creator/` (Layer 2) — Creator identity, attribution, canonical creator records, and website application.
