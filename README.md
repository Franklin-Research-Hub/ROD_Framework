# ROD Framework

## 1. Purpose
`Franklin-Research-Hub/ROD_Framework` is a governed, proprietary framework archive under Victoria Love Franklin. It documents working architecture, governance, metadata, and creator attribution.

## 2. Navigation
- [Table of Contents](TABLE-OF-CONTENTS.md) — current repository-wide navigation.
- [Master Tree and Branch Document](MASTER-TREE-BRANCH.md) — canonical structural authority.
- [Working Index and Metadata Definitions](INDEX-METADATA-DEFINITIONS.md) — terminology and classification.
- [Contributing](CONTRIBUTING.md) — controlled change workflow.
- [Notice](NOTICE.md) and [License](LICENSE.md) — ownership notice and usage terms.

## 3. Current Branches
- [Foundation](Foundation/README.md), Layer 1, defines structural, governance, metadata, and validation rules.
- [Creator](Creator/README.md), Layer 2, applies those rules to creator records and website presentation. Records are registered through [Creator/INDEX.md](Creator/INDEX.md).

The repository root is a container, not a numbered layer. `Creator/` depends on `Foundation/`, not the reverse.

## 4. Reading Rules
Section numbers are local document-order labels, not framework node identifiers. The Creator anchor `0.00` identifies a record, not a section, layer, or document version.

The master tree governs current navigation; it is not an exhaustive physical file inventory. Older materials outside its scope are not current structural authorities.

## 5. Ownership and Status
The framework remains under active development. These documents establish a working baseline, subject to controlled revision rather than a permanently final architecture.

Ownership and approval authority remain with Victoria Love Franklin. Repository visibility does not grant usage rights; see [LICENSE.md](LICENSE.md).
