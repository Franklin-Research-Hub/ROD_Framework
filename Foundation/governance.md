# Governance

## 1. Purpose
This document establishes governance rules for the Foundation layer.

## 2. Scope
Applies to all documents in `Foundation/`, including structure, metadata definitions, validation references, and the tree/branch definition.

## 3. Principles
- Clarity over brevity.
- Layer boundaries are preserved.
- Structural changes are documented before they are applied.
- Creator-specific records belong to Layer 2.
- Foundation defines the rules that allow creator metadata to include biography and portfolio material.

## 4. Change Control
Any change to a Foundation document must:
1. Preserve Layer 1 as the repository base.
2. Remain consistent with every other Foundation document.
3. Update `tree-branch.md` if files are added, renamed, or removed.
4. Respect the distinction between foundational rules and creator-layer records.

## 5. Stewardship
Stewardship of the framework rests with its creator, Victoria Love Franklin, unless superseded by documented governance.

## 6. Summary
Governance keeps the Foundation stable, reviewable, and continuous.
