# Metadata Model

## 1. Purpose
This document defines how metadata is expressed in the framework.

## 2. Foundation-Level Metadata
Each Foundation document carries:
- **Name**: the document title
- **Role**: its stated responsibility
- **Layer**: Layer 1
- **Position**: its place in the tree/branch

## 3. Higher-Layer Metadata Rule
In higher layers, metadata lives in the structured record label and its associated record file.

Example label format:

`[<version> :: <name> - <role>](<file>)`

Example:

`[0.00 :: Victoria Love Franklin - Creator](../Creator/0.00-creator.md)`

## 4. Creator Metadata Rule
Creator metadata may include:
- version
- creator name
- creator role
- biography
- portfolio reference
- extended profile material

## 5. Structural Rule
Foundation defines the metadata rules. Creator records implement them in Layer 2.

## 6. Summary
The metadata model preserves meaning, placement, and document relationships across the repository structure.
