# Validation References

## 1. Purpose
This document lists the criteria used to validate the Foundation layer.

## 2. Validation Checklist
| Check | Criterion |
|---|---|
| Naming | Folder and file names match the tree in `tree-branch.md` |
| Role | Each document stays within its stated responsibility |
| Layering | Foundation contains only Layer 1 documents |
| Metadata | Metadata rules support creator records that may include biography and portfolio material |
| Governance | Changes follow `governance.md` |
| Tree | The raw tree matches the actual folder contents |

## 3. Validation Timing
Validate whenever a Foundation file is added, renamed, removed, or substantially edited.

## 4. Summary
Validation keeps the Foundation coherent and accurate.
