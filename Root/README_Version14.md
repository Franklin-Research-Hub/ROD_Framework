# ROD Framework

The `ROD_Framework` repository is a governed documentation framework under active development.

It organizes repository structure through root authority documents and branch-owned documentation layers. The current documented branches are:

- `Foundation/`
- `Creator/`

This repository is maintained as a working framework baseline. Its structure, terminology, and governance may expand as the framework matures.

## 1. Purpose
This repository establishes the current structural baseline for the ROD Framework.

It is intended to:
- define repository-wide structure
- document branch relationships
- preserve creator attribution
- support controlled framework growth
- maintain consistent metadata and navigation practices
